# Pasapalabra - Portal Far

Fitxers col·locats dins de `apps/pasapalabra/`:

- `temporada1/`: curriculars i generals.
- `temporada2/`: Megamix Juvenil.
- `especials/`: versions específiques Castellà/Rus o suport rus.

S’ha afegit una barra flotant d’idioma: Castellà / Valencià / Rus.

Nota: es conserva el contingut original de cada app. Quan l’app ja tenia suport rus, el botó activa/oculta el rus. El valencià tradueix la interfície comuna del portal; les preguntes originals es mantenen.
